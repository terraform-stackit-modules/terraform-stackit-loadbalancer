# Terraform STACKIT Load Balancer module

Terraform module which provisions a STACKIT Load Balancer on [STACKIT](https://www.stackit.de/en/) — either an L4 **Network Load Balancer** ([`stackit_loadbalancer`](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/loadbalancer)) or an L7 **Application Load Balancer** ([`stackit_application_load_balancer`](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/application_load_balancer)), selected with a single `type` input.

Inspired by [terraform-aws-alb](https://github.com/terraform-aws-modules/terraform-aws-alb), which deploys either an ALB or an NLB from one module. Note: on AWS both are the same resource (`aws_lb` + `load_balancer_type`); on STACKIT they are **two separate resources**, so this module gates them with `count` on `type` and exposes a separate input set per type.

## Usage — Network Load Balancer (L4, default)

```hcl
module "nlb" {
  source  = "terraform-stackit-modules/loadbalancer/stackit"
  version = ">= 1.0.0"

  project_id       = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  type             = "network" # default
  name             = "app-nlb"
  plan_id          = "p10"
  external_address = "203.0.113.10"

  networks = [{ network_id = "xxxx", role = "ROLE_LISTENERS_AND_TARGETS" }]

  network_target_pools = [{
    name        = "app-pool"
    target_port = 80
    targets     = [{ display_name = "app-1", ip = "10.20.0.100" }]
  }]

  network_listeners = [{
    display_name = "app-listener"
    port         = 80
    protocol     = "PROTOCOL_TCP"
    target_pool  = "app-pool"
  }]
}
```

## Usage — Application Load Balancer (L7)

```hcl
module "alb" {
  source  = "terraform-stackit-modules/loadbalancer/stackit"
  version = ">= 1.0.0"

  project_id       = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  type             = "application"
  name             = "app-alb"
  plan_id          = "p10"
  external_address = "203.0.113.20"

  networks = [{ network_id = "xxxx", role = "ROLE_LISTENERS_AND_TARGETS" }]

  application_target_pools = [{
    name        = "web-pool"
    target_port = 80
    targets     = [{ display_name = "web-1", ip = "10.30.0.100" }]
  }]

  application_listeners = [{
    name     = "http"
    port     = 80
    protocol = "PROTOCOL_HTTP"
    http = {
      hosts = [{
        host  = "*.example.com"
        rules = [{ target_pool = "web-pool", path = { prefix = "/" } }]
      }]
    }
  }]
}
```

See [`examples/basic`](./examples/basic) (network / L4) and [`examples/application`](./examples/application) (L7) — both self-contained (`project_id` only): they build a network via the published `terraform-stackit-network` module, reserve a public IP, and use a documented placeholder target IP.

## Choosing a type

- **`network`** (L4) — TCP/UDP/TCP_PROXY/TLS_PASSTHROUGH; source-IP session persistence; optional
  ARGUS observability credential. Uses `network_listeners`, `network_target_pools`, `network_options`.
- **`application`** (L7) — HTTP/HTTPS with host + path routing, header/query matching, cookie
  persistence, websockets, TLS termination (`https.certificate_config`) and WAF (`waf_config_name`).
  Uses `application_listeners`, `application_target_pools`, `application_options`.

## Notes

- Provide only the input set matching `type`; the other set is ignored (its resource is not created).
- A listener references a target pool by `name`; `targets[*].ip` are the PRIVATE IPs of your backends.
- `external_address` is the public IP the LB is exposed on (reserve one with `stackit_public_ip`).
- Read-only security-group IDs are exposed as outputs for cross-network targets (see outputs).
- `network_listeners[*].server_name_indicators` is intentionally NOT exposed (deprecated in the provider).

## Terratest

The `test/` directory holds Terratest integration tests. CI runs only the `basic` (network) example; the `application` example self-skips unless `TERRATEST_RUN_ALL` is set (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-loadbalancer
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
TERRATEST_RUN_ALL=1 go test -v -timeout 45m ./...
```
